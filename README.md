# \# CyberSecurityChatBot - Part 2

# 

# A WinForms chatbot that educates South African citizens on cybersecurity topics.

# 

# \## Features

# \- GUI built with Windows Forms

# \- Keyword recognition for cybersecurity topics

# \- Sentiment detection based on user mood

# \- Memory and recall of user details

# \- Random varied responses

# \- Voice greeting on startup

# 

# \## Topics Covered

# \- Password Safety

# \- Phishing Awareness

# \- Privacy Tips

# \- Scam Awareness

# \- Malware Protection

# \- Safe Browsing

# 

# \## How to Run

# 1\. Clone the repository

# 2\. Open CyberSecurityChatBot.sln in Visual Studio

# 3\. Build the solution (Ctrl + Shift + B)

# 4\. Run the project (click Start)

# 5\. Place your greeting.wav file in the same folder as the .exe

# 

# \## Requirements

# \- Visual Studio 2019 or later

# \- .NET Framework 4.7.2 or later

# \- Windows OS
